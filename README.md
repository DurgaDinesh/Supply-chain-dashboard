# Supply-chain-dashboard
End-to-end Power BI supply chain analytics on the DataCo dataset — star-schema model, 49 DAX measures, and a 3-page report covering sales, delivery performance, and order-level detail.


A Power BI report built on the DataCo Global supply chain dataset (180K order lines, 2015–2018). The semantic model restructures a flat source table into a star schema — dedicated Date, Customer, Product, Geography, Shipping, and Status dimensions wired to a single fact — and layers on 49 DAX measures across sales & profit, delivery performance, time intelligence, and customer/product analytics. The three-page report delivers an executive summary, a delivery & operations view, and a paginated-style order-detail page with full slicer filtering, styled in a custom dark theme.
